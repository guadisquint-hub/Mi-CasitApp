# 🎁 Mi CasitApp - Lista de Deseos para Tienda de Regalos

**Mi CasitApp** es una mini aplicación web liviana y receptiva diseñada para gestionar listas de regalos de cumpleaños y eventos especiales. Permite a los clientes y sus familias elegir regalos, agregar empaques especiales y coordinar compras de forma sencilla e intuitiva.

---

## 🎨 Características Principales

- **Diseño Pastel Elegante:** Interfaz limpia con tonos degradados pastel (rosa, lavanda y azul menta).
- **Modo Tienda (Administrador):** Creación de nuevas listas de cumpleañeros y carga rápida de productos con precio, emoji y detalles.
- **Modo Familia (Compradores):** Vista interactiva para que abuelos, tíos y amigos seleccionen los regalos que desean comprar.
- **Bolsa de Regalo Adicional:** Opción integrada para sumar embalaje de lujo o bolsa de regalo con costo adicional computable al total.
- **Remoción Automática:** Los productos reservados/comprados desaparecen de la lista activa en tiempo real para evitar compras duplicadas.
- **Persistencia Local:** Los datos se guardan en el navegador (`localStorage`) sin necesidad de bases de datos complejas.

## 🚀 Cómo desplegar en GitHub Pages

1. Sube el archivo `index.html` a este repositorio.
2. Ve a **Settings** > **Pages**.
3. En la sección **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
4. Haz clic en **Save**. ¡Tu app estará online en 1-2 minutos!
